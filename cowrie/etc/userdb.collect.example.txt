# passwords for root (plus the two service accounts), so that internet scanners
# working through a typical wordlist get in after a handful of tries and you
# record their sessions. Everything not listed is still refused, so a scanner
# that tests a random password does not succeed on the first request.
#
# Use userdb.example.txt ("stealth", three exact pairs) instead when the goal is
# to look as much like a real hardened-but-weak box as possible and you accept
# that very few automated attackers will get in.
#

#   * every accepted user must exist in honeyfs-overlay/etc/passwd;
#   * for each user, the LAST line is the password hashed into /etc/shadow, so
#     keep the one you want an attacker to "crack" last.
